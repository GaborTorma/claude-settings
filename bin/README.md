# bin — PATH-ra kerülő parancsok

Symlinkek a tényleges eszközökre; a `scripts/install.sh` mindent, ami itt van és
futtatható, felvisz a `~/.local/bin`-be (fájlnév = parancsnév). Maguk az
eszközök saját mappában élnek, nem itt.
